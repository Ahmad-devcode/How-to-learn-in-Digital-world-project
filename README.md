# 🎓 FutureLearn — Courses for Tomorrow's World

> Discover the most in-demand courses and learn effectively with digital tools and platforms.

FutureLearn is a modern, responsive learning-platform website that helps learners discover in-demand
skills (AI & Machine Learning, Cybersecurity, Data Science, Web Development, Digital Marketing and
more), learn **how to learn** with proven strategies, explore top learning platforms and resources,
and get inspired by real success stories.

## ✨ Features

- **Course catalog** — in-demand courses with demand-level badges and rich descriptions
- **How to Learn** — practical learning strategies and tips for the digital world
- **Resources** — curated directory of learning platforms and tools
- **Success stories** — real learner journeys to stay motivated
- **FAQ section** — answers to common learning questions
- **Fully responsive** — mobile-first design with smooth Framer Motion animations

## 🛠️ Tech Stack

| Technology | Purpose |
| ---------- | ------- |
| React 18 + TypeScript | UI components with type safety |
| Vite 5 | Fast build tool & dev server |
| Tailwind CSS 3 | Utility-first styling |
| React Router 6 | Client-side routing |
| Framer Motion | Animations & transitions |
| Lucide React | Clean icon set |
| ESLint | Code quality |

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ and npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Ahmad-devcode/How-to-learn-in-Digital-world-project.git

# Move into the project folder
cd How-to-learn-in-Digital-world-project

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 📜 Available Scripts

| Script | Description |
| ------ | ----------- |
| `npm run dev` | Start the development server |
| `npm run build` | Build the app for production |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint over the project |
